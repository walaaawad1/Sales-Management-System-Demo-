الخطوات//

تثبيت الاعتمادات
npm install

إنشاء ملف البيئة
.env.local

وإضافة المفتاح:
GEMINI_API_KEY=YOUR_API_KEY

تشغيل المشروع
npm run dev

سيعمل المشروع على:
http://localhost:3000
